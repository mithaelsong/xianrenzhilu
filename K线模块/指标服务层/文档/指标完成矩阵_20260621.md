| 字段 | 含义 |

| figure | 输出 line/bar/band/point/label/range 等定义是否完整 |
| overlay输出 | 是否能生成 KX-FN-25 标准 overlay |
| settings | 是否能设置全部参数和样式 |
| chip | 是否有对应 pane 顶部小标签/tooltip |
| overlay消费 | UI-12/UI-13 是否通过标准接口渲染 |
| 多实例 | 同一指标多实例是否互不影响 |
| 显隐删除 | 每个实例是否独立显隐/删除 |
| 截图验收 | 是否实际截图确认 |
| 状态 | 未开始/计算已有/迁移中/待截图/完成/打回 |
