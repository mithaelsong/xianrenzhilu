## 一、单根形态（Single Candle Patterns）

### 1️⃣ 锤子线（Hammer）

```
       最高价     ┃
       ─────     ┃
                 ┃
  ┌──────────┐   ┃   实体（小）
  │  收盘价/  │   ┃
  │  开盘价   │   ┃
  │          │   ┃
  │          │   ┃
  │          │   ┃   下影线（很长）
  │          │   ┃
  │          │   ┃
  └──────────┘   ┃
       最低价     ┃
```

- **方向**：看涨反转 📈
- **意义**：下跌趋势中，空头把价格压到很低，但多头强力拉回——说明底部买盘强劲
- **特征**：下影线≥实体2倍，上影线极短或无
- **可信度**：⭐⭐⭐（高）
- **搭配**：出现在支撑位/放量更可靠

---

### 2️⃣ 吊颈线（Hanging Man）

```
       最低价     ┃
       ─────     ┃
                 ┃
  ┌──────────┐   ┃   下影线（很长）
  │          │   ┃
  │          │   ┃
  │          │   ┃
  │          │   ┃
  │  开盘价/  │   ┃
  │  收盘价   │   ┃   实体（小）
  └──────────┘   ┃
       ─────     ┃
       最高价     ┃   ← 趋势顶部
```

- **方向**：看跌反转 📉
- **意义**：上涨趋势中，价格一度被打压很深但收了回来——说明顶部抛压已经出现
- **特征**：下影线≥实体2倍，上影线极短，出现在上涨后
- **可信度**：⭐⭐⭐（高）
- **注意**：锤子线和吊颈线形态完全一样，区别只在位置——底部的叫锤子线，顶部的叫吊颈线

---

### 3️⃣ 十字星（Doji）

```
       最高价     ┃
       ─────     ┃
                 ┃
  ┌──────────┐   ┃   上影线
  │  ─── ─── │   ┃   ← 开盘价=收盘价（实体极小）
  └──────────┘   ┃   下影线
       ─────     ┃
       最低价     ┃
```

- **方向**：中性反转 🔄
- **意义**：多空力量均衡，谁都没占上风——通常意味着趋势需要重新选择方向
- **特征**：开盘价≈收盘价（实体≤整根K线的5%）
- **可信度**：⭐⭐（中）
- **注意**：在趋势末端出现→反转信号；在盘整中出现→可能继续盘整

---

### 4️⃣ 长腿十字星（Long-Legged Doji）

```
       最高价     ┃
       ─────     ┃
                 ┃
  ┌──────────┐   ┃   上影线（很长）
  │          │   ┃
  │  ── ──   │   ┃   ← 开盘价=收盘价
  │          │   ┃
  └──────────┘   ┃   下影线（很长）
       ─────     ┃
       最低价     ┃
```

- **方向**：中性反转 🔄
- **意义**：价格在最高和最低之间大幅波动，最终收在开盘价——多空激烈争夺
- **特征**：上下影线都很长，实体极小
- **可信度**：⭐⭐（中）
- **别名**：高浪十字星（High Wave Doji）

---

### 5️⃣ 墓碑十字星（Gravestone Doji）

```
       最高价     ┃
       ─────     ┃
                 ┃
  ┌──────────┐   ┃
  │          │   ┃   上影线（长）
  │          │   ┃
  │  ───    │   ┃   ← 开盘价=收盘价=最低价
  └──────────┘   ┃
       最高价     ┃   ← 也是最低价
```

- **方向**：看跌反转 📉
- **意义**：开盘后价格猛烈上冲，但随后被打回原形收在最低——多头冲锋被彻底击退
- **特征**：上影线长，无下影线，开盘价=收盘价=最低价
- **可信度**：⭐⭐⭐（高）
- **注意**：顶部出现非常可靠，像墓碑一样寓意趋势"死亡"

---

### 6️⃣ 蜻蜓十字星（Dragonfly Doji）

```
       最高价     ┃   ← 开盘价=收盘价=最高价
       ─────     ┃
  ┌──────────┐   ┃
  │  ───    │   ┃
  │          │   ┃
  │          │   ┃
  │          │   ┃   下影线（长）
  └──────────┘   ┃
       ─────     ┃
       最低价     ┃
```

- **方向**：看涨反转 📈
- **意义**：开盘后价格暴跌，但多头顽强拉回最高点——抛压被完全消化
- **特征**：下影线长，无上影线，开盘价=收盘价=最高价
- **可信度**：⭐⭐⭐（高）
- **注意**：底部出现非常可靠，蜻蜓点水后起飞

---

### 7️⃣ 光头光脚线（Marubozu）

```
  ┌──────────────┐
  │              │
  │              │   实体（很长）
  │              │   无上下影线
  │              │
  └──────────────┘
```

- **方向**：趋势延续 →
  - 白色/绿色（阳线）= 强势看涨 🟢
  - 黑色/红色（阴线）= 强势看跌 🔴
- **意义**：价格从开盘到收盘一路单向运行，没有回头——单边压倒性优势
- **特征**：无上下影线，实体占总长度的80%以上
- **可信度**：⭐⭐⭐（高）

---

### 8️⃣ 纺锤线（Spinning Top）

```
       最高价     ┃
       ─────     ┃
                 ┃
  ┌──────────┐   ┃   上影线
  │  实体（小）│   ┃
  └──────────┘   ┃   下影线
       ─────     ┃
       最低价     ┃
```

- **方向**：犹豫/盘整 ↔️
- **意义**：多空都在试探，没人能推动趋势——市场在犹豫
- **特征**：实体较小（5%-30%），上下影线明显
- **可信度**：⭐（低）
- **注意**：单独出现意义不大，需要结合前后K线和位置判断

---

### 9️⃣ 长下影线（Long Lower Shadow）

```
       最高价     ┃
       ─────     ┃
  ┌──────────┐   ┃
  │ 实体（中）│   ┃
  │          │   ┃
  │          │   ┃
  │          │   ┃   下影线（≥实体2倍）
  └──────────┘   ┃
       ─────     ┃
       最低价     ┃
```

- **方向**：看涨信号 📗
- **意义**：价格被砸低后强力反弹——多头开始在低位买入
- **特征**：下影线≥实体2倍，实体不超过整根40%
- **可信度**：⭐⭐（中）

---

### 🔟 长上影线（Long Upper Shadow）

```
       最高价     ┃
       ─────     ┃
  ┌──────────┐   ┃   上影线（≥实体2倍）
  │          │   ┃
  │          │   ┃
  │ 实体（中）│   ┃
  └──────────┘   ┃
       ─────     ┃
       最低价     ┃
```

- **方向**：看跌信号 📕
- **意义**：价格被拉高后大幅回落——空头在高位抛售
- **特征**：上影线≥实体2倍，实体不超过整根40%
- **可信度**：⭐⭐（中）

## 二、双根形态（Two-Candle Patterns）

### 1️⃣1️⃣ 看涨吞没（Bullish Engulfing）

```
  第一根（阴）       第二根（阳）
  ┌────┐          ┌──────────┐
  │    │          │          │
  │  ▓▓ │          │          │
  │  ▓▓ │          │  ───    │  ← 第二根完全包住第一根
  │  ▓▓ │          │          │
  │  ▓▓ │          │          │
  └────┘          └──────────┘
    ↘                ↗
```

- **方向**：看涨反转 📈
- **意义**：第一天空头占优（阴线），第二天多头直接反包——说明多头接管市场
- **特征**：第二根阳线实体完全包裹第一根阴线实体（含影线更好）
- **可信度**：⭐⭐⭐（高）
- **条件**：出现在下跌趋势底部

---

### 1️⃣2️⃣ 看跌吞没（Bearish Engulfing）

```
  第一根（阳）       第二根（阴）
  ┌────┐          ┌──────────┐
  │    │          │  ▓▓▓▓▓▓  │
  │    │          │  ▓▓▓▓▓▓  │
  │  ─── │          │  ▓▓▓▓▓▓  │  ← 第二根完全包住第一根
  │    │          │  ▓▓▓▓▓▓  │
  │    │          │  ▓▓▓▓▓▓  │
  └────┘          └──────────┘
    ↗                ↘
```

- **方向**：看跌反转 📉
- **意义**：第一天多头占优（阳线），第二天空头直接反包——空头接管市场
- **特征**：第二根阴线实体完全包裹第一根阳线实体
- **可信度**：⭐⭐⭐（高）
- **条件**：出现在上涨趋势顶部

---

### 1️⃣3️⃣ 刺透形态（Piercing Line）

```
  第一根（阴）       第二根（阳）
  ┌────┐          ┌──────────┐
  │    │          │          │
  │ ▓▓ │          │ ───      │
  │ ▓▓ │          │          │  ← 收在中线以上
  │ ▓▓←┼─────────│─ ─ ─ ─  │  ← 前一根中线
  │ ▓▓ │          │          │
  └──┼─┘          └──────────┘
     ↓                  ↗
   第二根开盘低于前低
```

- **方向**：看涨反转 📈
- **意义**：第二根开盘跌得更低但收盘涨过第一根中线——多头正在反攻
- **特征**：第二根阳线开盘低于前低，收盘高于前实体中点
- **可信度**：⭐⭐（中）
- **注意**：吞没的弱化版，不如吞没强烈

---

### 1️⃣4️⃣ 乌云盖顶（Dark Cloud Cover）

```
  第一根（阳）       第二根（阴）
  ┌────┐          ┌──────────┐
  │    │          │  ▓▓▓▓▓▓  │
  │    │          │  ▓▓▓▓▓▓  │
  │  ──┼─────────│ ─ ─ ─ ─ │  ← 前一根中线
  │    │          │  ▓▓▓▓▓▓←┼── 跌破中线
  │    │          │  ▓▓▓▓▓▓  │
  └────┘          └──────────┘
    ↗                  ↘
   第二根开盘高于前高
```

- **方向**：看跌反转 📉
- **意义**：第二根开盘更高然后暴跌，跌穿前一根阳线的中线——空头反扑猛烈
- **特征**：第二根阴线开盘高于前高，收盘低于前实体中点
- **可信度**：⭐⭐（中）
- **注意**：看跌吞没的弱化版

---

### 1️⃣5️⃣ 看涨孕线（Bullish Harami）

```
  第一根（大阳）          第二根（小阴）
  ┌────────────────┐
  │                │
  │                │
  │                │   ┌────┐
  │                │   │ ▓▓ │   ← 被包含
  │                │   └────┘
  └────────────────┘
          ↙
```

- **方向**：看涨反转 📗（较弱）
- **意义**：第一天大阳线，第二天小阴线完全被包含——多头势头减弱但空头没反攻动力量
- **特征**：第二根实体完全在第一根实体范围内
- **可信度**：⭐（低）
- **注意**：孕线是"孕育"的意思，大K线生出小K线

---

### 1️⃣6️⃣ 看跌孕线（Bearish Harami）

```
  第一根（大阴）          第二根（小阳）
  ┌────────────────┐
  │ ▓▓▓▓▓▓▓▓▓▓▓▓  │
  │ ▓▓▓▓▓▓▓▓▓▓▓▓  │
  │ ▓▓▓▓▓▓▓▓▓▓▓▓  │   ┌────┐
  │ ▓▓▓▓▓▓▓▓▓▓▓▓  │   │    │   ← 被包含
  │ ▓▓▓▓▓▓▓▓▓▓▓▓  │   └────┘
  └────────────────┘
          ↘
```

- **方向**：看跌反转 📕（较弱）
- **意义**：第一天大阴线，第二天小阳线完全被包含——空头势头减弱但多头没反攻
- **特征**：第二根实体完全在第一根实体范围内
- **可信度**：⭐（低）

---

### 1️⃣7️⃣ 十字孕线（Harami Cross）

```
  第一根（大实体）          第二根（十字星）
  ┌────────────────┐
  │                │      ───  ← 最高
  │                │    ┌───┐
  │                │    │───│  ← 开=收
  │                │    └───┘
  │                │      ───  ← 最低
  └────────────────┘
         ↙    被包含
```

- **方向**：反转信号 🔄（比孕线强）
- **意义**：大K线中出现十字星——趋势动能衰竭，反转概率增大
- **特征**：第一根大实体，第二根十字星完全被包含
- **可信度**：⭐⭐（中）

---

### 1️⃣8️⃣ 镊子顶（Tweezer Top）

```
      第二根        第一根
      ─────        ─────  ← 最高点相同
  ┌──────────┐  ┌────┐
  │          │  │    │
  │          │  │ ▓▓ │
  └──────────┘  └────┘
     (阳/阴)      (阴/阳)
```

- **方向**：看跌反转 📕
- **意义**：两根K线最高点相同——说明该价位有明显阻力，两次都无法突破
- **特征**：两根K线最高价相等（或非常接近）
- **可信度**：⭐（低）

---

### 1️⃣9️⃣ 镊子底（Tweezer Bottom）

```
      第一根        第二根
  ┌────┐        ┌──────────┐
  │ ▓▓ │        │          │
  │ ▓▓ │        │          │
  └────┘        └──────────┘
     ─────        ─────  ← 最低点相同
```

- **方向**：看涨反转 📗
- **意义**：两根K线最低点相同——说明该价位有明显支撑，两次都跌不破
- **特征**：两根K线最低价相等
- **可信度**：⭐（低）

---

### 2️⃣0️⃣ 跳空缺口（Window / Gap）

```
                  ┌────┐
                  │    │
                  │    │  第二根
  ┌────┐          └────┘
  │    │    ← 缺口（没有交易）
  │    │    ← Gap
  └────┘
  第一根
```

- **方向**：趋势确认 →
- **意义**：价格跳空越过前一根K线的范围，留下无交易的空白区域
  - **突破缺口**：突破关键位，趋势启动
  - **中继缺口**：趋势中途，加速信号
  - **衰竭缺口**：趋势末端，即将反转
- **特征**：前根最高<后根最低（上涨缺口）或前根最低>后根最高（下跌缺口）
- **可信度**：⭐⭐（中）
- **注意**：缺口回补（价格回到缺口区域）可能意味着趋势减弱

---

### 2️⃣1️⃣ 看涨分手线（Bullish Separating Lines）

```
  第一根（阴）     第二根（阳）
  ┌────┐         ┌──────────┐
  │    │         │          │
  │ ▓▓ │         │          │
  │ ▓▓ │         │ ─── ───  │  ← 开盘价相同
  │ ▓▓ │         │          │
  │ ▓▓ │         │          │
  └────┘         └──────────┘
```

- **方向**：趋势延续 ↗
- **意义**：阴线后，第二根同开盘价反向上攻——空头→多头的明确切换
- **特征**：阴线+阳线，开盘价相同
- **可信度**：⭐（低）

---

### 2️⃣2️⃣ 看跌分手线（Bearish Separating Lines）

```
  第一根（阳）     第二根（阴）
  ┌────┐         ┌──────────┐
  │    │         │ ▓▓▓▓▓▓▓  │
  │    │         │ ▓▓▓▓▓▓▓  │
  │ ─── ───      │ ▓▓▓▓▓▓▓  │  ← 开盘价相同
  │    │         │ ▓▓▓▓▓▓▓  │
  │    │         │ ▓▓▓▓▓▓▓  │
  └────┘         └──────────┘
```

- **方向**：趋势延续 ↘
- **意义**：阳线后，第二根同开盘价反向下杀——多头→空头的明确切换
- **特征**：阳线+阴线，开盘价相同
- **可信度**：⭐（低）

## 三、三根及以上形态（Multi-Candle Patterns）

### 2️⃣3️⃣ 晨星（Morning Star）

```
   第一根（大阴）   第二根（小实体）   第三根（大阳）
                      ───── ─────
  ┌────┐            ┌──────────┐      ┌──────────┐
  │ ▓▓ │            │          │      │          │
  │ ▓▓ │            │          │      │          │
  │ ▓▓←┼───────────│ ───     │      │          │
  │ ▓▓ │            │          │      │          │
  └────┘            └──────────┘      │          │
    ↘                                 │          │
                         ───── ─────   │          │
                      ← 跳空缺口 →    └──────────┘
                                         ↗ 收过中线
```

- **方向**：看涨反转 📈（经典）
- **意义**：大跌→犹豫→大涨，空头力量衰竭，多头接管
- **特征**：大阴线+小实体（可能十字星）+大阳线收过前阴中线
- **可信度**：⭐⭐⭐（高）
- **级别**：最可靠的底部反转形态之一

---

### 2️⃣4️⃣ 黄昏星（Evening Star）

```
   第一根（大阳）   第二根（小实体）   第三根（大阴）
  ┌──────────┐      ┌──────────┐      ┌────┐
  │          │      │          │      │ ▓▓←┼─ 跌过中线
  │          │      │          │      │ ▓▓ │
  │          │      │ ─── ───  │      │ ▓▓ │
  │          │      │          │      │ ▓▓ │
  └──────────┘      └──────────┘      └────┘
    ↗                 ───── ─────       ↘
                   ← 跳空缺口 →
```

- **方向**：看跌反转 📉（经典）
- **意义**：大涨→犹豫→大跌，多头力量衰竭，空头接管
- **特征**：大阳线+小实体（可能十字星）+大阴线跌破前阳中线
- **可信度**：⭐⭐⭐（高）
- **级别**：最可靠的顶部反转形态之一，晨星的镜像

---

### 2️⃣5️⃣ 弃婴形态（Abandoned Baby）

```
  晨星版（看涨）：
    第一根（阴）  第二根（十字星）  第三根（阳）
  ┌────┐                         ┌──────────┐
  │ ▓▓ │        ───              │          │
  │ ▓▓ │      ┌───┐              │          │
  │ ▓▓ │      │───│  ← 十字星    │          │
  │ ▓▓←┼─缺口→└───┘  ← 与两边都跳空  │          │
  └────┘        ───              └──────────┘
                                    ↗
```

- **方向**：反转信号 🔄
- **意义**：晨星/黄昏星的加强版——中间的十字星与前后都有跳空缺口，表示市场"断档"
- **特征**：中间十字星与前后K线都有跳空缺口
- **可信度**：⭐⭐⭐（高）
- **注意**：当晨星/黄昏星出现弃婴特征时，反转概率更高

### 2️⃣6️⃣ 三只乌鸦（Three Black Crows）

```
       第一根          第二根          第三根
  ┌──────────┐
  │          │
  │          │     ┌──────────┐
  │          │     │ ▓▓▓▓▓▓▓  │
  └──────────┘     │ ▓▓▓▓▓▓▓  │     ┌──────────┐
       ↘           │ ▓▓▓▓▓▓▓  │     │ ▓▓▓▓▓▓▓  │
                   └──────────┘     │ ▓▓▓▓▓▓▓  │
                       ↘           │ ▓▓▓▓▓▓▓  │
                                    └──────────┘
                                          ↘
```

- **方向**：看跌反转 📉
- **意义**：连续三根实体相近的阴线，每根收盘越来越低——空头连续碾压
- **特征**：三根大阴线，实体相近，收盘价逐次降低
- **可信度**：⭐⭐⭐（高）
- **注意**：出现在上涨后是顶部反转，出现在下跌后可能只是加速下跌

       第一根          第二根          第三根

- **特征**：三根大阳线，实体相近，收盘价逐次升高
- **可信度**：⭐⭐⭐（高）
- **注意**：是"三只乌鸦"的看涨镜像。如果实体越来越小，说明多头势能减弱

### 2️⃣8️⃣ 上升三法（Rising Three Methods）

```
  第一根（大阳）  中间三根（小阴）  最后一根（大阳）
  ┌──────────┐   ┌┐ ┌┐ ┌┐       ┌──────────┐
  │          │   ││ ││ ││       │          │
  │  ───    │   ││←││←││ 不跌破 │          │
  │          │   ││ ││ ││       │          │
  │          │   └┘ └┘ └┘       └──────────┘
  └──────────┘                     ↗ 创新高
      ↗         ↘↘↘
```

- **方向**：趋势延续 ↗
- **意义**：上升趋势中的"休整"——三根小阴线回撤但不破前低，最后一根大阳线继续上攻
- **特征**：大阳+三小阴+大阳，中间不跌破第一根最低点
- **可信度**：⭐⭐（中）

- **方向**：趋势延续 ↘
- **意义**：下跌趋势中的"休整"——三根小阳线反弹但不破前高，最后一根大阴线继续下杀
- **特征**：大阴+三小阳+大阴，中间不突破第一根最高点
- **可信度**：⭐⭐（中）
