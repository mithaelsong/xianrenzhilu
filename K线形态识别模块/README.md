# K线形态识别模块

独立业务模块。职责：消费 K线数据，执行 K线形态识别，输出形态结果、图表标记、提醒事件和设置配置。

## 边界
- 不属于 `K线模块` 内部服务层。
- 不绘制 UI，不直接读写数据库，不直接联网。
- K线模块只通过接口提供 Candle 数据，并消费本模块输出的标准标记/叠加载荷。
- UI 设置面板保留在 `UI模块/UI皮肤`，通过 `KPPatternSettingsCatalog` 获取配置。

## 分层
- 管理层：入口、注册表、公共类型。
- 形态定义层：29 个内置形态定义、自定义形态规则。
- 识别引擎层：识别算法、Watcher。
- 接口适配层：K线输入适配、信号/标记输出适配。
- 配置层：设置面板所需配置。
- 事件层：提示音/提醒事件生成。
- 测试层：模块结构和核心能力自检。
